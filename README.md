# أكاديمية نجد

موقع ثابت (HTML/CSS/JS) لطلاب جامعة الأمير مساعد بن عبدالرحمن.

| الصفحة | الملف |
|---|---|
| الرئيسية | `index.html` (و `home.html` تحوّل لها للروابط القديمة) |
| الخطط الدراسية | `plans.html` |
| الجدول الدراسي | `schedule.html` |
| حاسبة المعدل | `gpa.html` |
| الشروحات | `lessons.html` |
| مساعدك الدراسي | `assistant.html` |
| التدريب التعاوني (مفتوحة للكل) | `coop.html` |
| المتجر (منتجات سلة/زد، مفتوحة للكل) | `store.html` |
| لوحة الإدارة (للمشرف) | `admin.html` |
| تسجيل الدخول / إنشاء حساب | `login.html` / `register.html` |
| خطط كلية العلوم الإدارية والمالية (الصفحة الأصلية) | `college-plans.html` |

## الملفات المشتركة
- `assets/css/najd.css`: التصميم والألوان المشتركة (الهيدر، الفوتر، البطاقات، الأزرار).
- `assets/js/layout.js`: يبني الهيدر والفوتر في كل صفحة. روابط الصفحات تتعدل من `LINKS` في أول الملف.
- `assets/js/auth.js`: إعدادات Firebase، وتسجيل الدخول، ومزامنة التقدم مع Firestore.
- `assets/js/auth-forms.js`: نماذج الدخول والتسجيل.

## الدخول
- الخطط والجدول والمعدل والشروحات والمساعد تحتاج تسجيل دخول.
- الرئيسية والتدريب التعاوني مفتوحة للكل.
- طرق الدخول: **حساب Gmail (قوقل)** أو **البريد الإلكتروني وكلمة المرور**.
- ملاحظة: القفل يصير في المتصفح (واجهة فقط). بيانات كل طالب نفسها محمية بقواعد Firestore.

## إعداد Firebase (مرة وحدة)
1. **Authentication ← Sign-in method**: فعّل **Google** و **Email/Password** (ما تحتاج خطة Blaze).
2. **Authentication ← Settings ← Authorized domains**: أضف النطاق اللي ينشر عليه الموقع (مثل `elite-122.github.io` أو نطاقك الخاص).
3. **Firestore Database**: أنشئ قاعدة البيانات، وبعدها من تبويب **Rules** الصق محتوى الملف `firestore.rules` واضغط **Publish**.

## لوحة الإدارة (`admin.html`)
فيها خمسة أقسام:
- **الإعلان:** شريط أعلى كل الصفحات.
- **المنتجات:** بطاقات في صفحة المتجر، وزر الطلب يفتح المنتج في سلة أو زد.
- **الشروحات:** فيديو يوتيوب أو PDF. الرابط محفوظ في `lessonLinks` ويقرأه بس المشترك، أو الكل لو الشرح مجاني.
- **المشتركين:** تفعّل اشتراك الطالب ببريده (`access/{البريد}`)، مع تاريخ انتهاء اختياري. البريد لازم يكون مؤكد.
- **التدريب التعاوني.**

ملاحظة: روابط يوتيوب «غير المدرجة» وروابط درايف يقدر المشترك يشاركها مع غيره. هذا حد طبيعي لأي موقع ثابت.

## إضافة مشرف
1. سجّل دخولك في الموقع وافتح `admin.html`. بيطلع لك رمز حسابك (UID).
2. في **Firestore Database** أنشئ مجموعة اسمها `admins`، و Document ID هو رمز حسابك، وأضف حقل `role` قيمته `owner`.
3. حدّث الصفحة، وتقدر بعدها تضيف الفرص وتعدلها وتحذفها.

## وش ينحفظ في الحساب؟
مستند `users/{uid}` فيه: الخطة (`najd_plans_v1`)، والمعدل (`najd_gpa_v1`)، والجدول (`stq_schedule_v1`).
الأدوات تشتغل بدون حساب وتحفظ في المتصفح. ولما يسجل الطالب دخوله، يتزامن تقدمه بين أجهزته تلقائيًا.

## تجربة الموقع على جهازك
```
python3 -m http.server 8000
```
وافتح `http://localhost:8000/`.

## الوضع الداكن واللغة
- زر 🌙/☀️ في الهيدر يبدّل بين الوضع الفاتح والداكن، ويتذكر اختيار الزائر. أول زيارة تتبع إعداد جهازه.
- زر EN/ع يبدّل لغة الموقع كامل. الترجمة في `assets/js/i18n.js`: كل سطر نص عربي وترجمته. لو أضفت نص جديد، أضف ترجمته هناك.
- المحتوى اللي تكتبه من لوحة الإدارة (أسماء المنتجات والجهات والشروحات) يظهر مثل ما كتبته.

## بعد أي تحديث للملفات
شغّل `python3 tools/set-version.py` عشان يتحدث رقم الإصدار في روابط الملفات، والمتصفحات تجيب النسخة الجديدة على طول.
