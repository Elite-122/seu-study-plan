# أكاديمية نجد

موقع ثابت (HTML/CSS/JS) لطلاب جامعة الأمير مساعد بن عبدالرحمن.

| الصفحة | الملف |
|---|---|
| الرئيسية | `index.html` (و `home.html` تحوّل لها للروابط القديمة) |
| الخطط الدراسية | `plans.html` |
| الجدول الدراسي | `schedule.html` |
| حاسبة المعدل | `gpa.html` |
| الشروحات | `lessons.html` |
| التدريب التعاوني (مفتوحة للكل) | `coop.html` |
| المتجر (منتجات سلة/زد، مفتوحة للكل) | `store.html` |
| اختبر نفسك (اختبارات تفاعلية) | `quiz.html` |
| تقييم المقررات وأعضاء هيئة التدريس | `ratings.html` |
| التقويم الأكاديمي (مفتوحة للكل) | `calendar.html` |
| حسابي | `account.html` |
| صفحة الخطأ 404 | `404.html` |
| لوحة الإدارة (للمشرف) | `admin.html` |
| تسجيل الدخول / إنشاء حساب | `login.html` / `register.html` |
| خطط كلية العلوم الإدارية والمالية (الصفحة الأصلية) | `college-plans.html` |

## الملفات المشتركة
- `assets/css/najd.css`: التصميم والألوان المشتركة (الهيدر، الفوتر، البطاقات، الأزرار).
- `assets/js/layout.js`: يبني الهيدر والفوتر في كل صفحة. روابط الصفحات تتعدل من `LINKS` في أول الملف.
- `assets/js/auth.js`: إعدادات Firebase، وتسجيل الدخول، ومزامنة التقدم مع Firestore.
- `assets/js/auth-forms.js`: نماذج الدخول والتسجيل.

## الدخول
- الخطط والجدول والمعدل والشروحات تحتاج تسجيل دخول.
- الرئيسية والتدريب التعاوني مفتوحة للكل.
- طرق الدخول: **حساب Gmail (قوقل)** أو **البريد الإلكتروني وكلمة المرور**.
- ملاحظة: القفل يصير في المتصفح (واجهة فقط). بيانات كل طالب نفسها محمية بقواعد Firestore.

## إعداد Firebase (مرة وحدة)
1. **Authentication ← Sign-in method**: فعّل **Google** و **Email/Password** (ما تحتاج خطة Blaze).
2. **Authentication ← Settings ← Authorized domains**: أضف النطاق اللي ينشر عليه الموقع (مثل `elite-122.github.io` أو نطاقك الخاص).
3. **Firestore Database**: أنشئ قاعدة البيانات، وبعدها من تبويب **Rules** الصق محتوى الملف `firestore.rules` واضغط **Publish**.

## لوحة الإدارة (`admin.html`)
فيها خمسة أقسام:
- **الإعلان:** شريط أعلى كل الصفحات.
- **المنتجات:** بطاقات في صفحة المتجر، وزر الطلب يفتح المنتج في سلة أو زد.
- **الشروحات:** فيديو يوتيوب أو PDF. الرابط محفوظ في `lessonLinks` ويقرأه بس المشترك، أو الكل لو الشرح مجاني.
- **المشتركين:** تفعّل اشتراك الطالب ببريده (`access/{البريد}`)، مع تاريخ انتهاء اختياري. البريد لازم يكون مؤكد.
- **التدريب التعاوني.**

ملاحظة: روابط يوتيوب «غير المدرجة» وروابط درايف يقدر المشترك يشاركها مع غيره. هذا حد طبيعي لأي موقع ثابت.

## إضافة مشرف
1. سجّل دخولك في الموقع وافتح `admin.html`. بيطلع لك رمز حسابك (UID).
2. في **Firestore Database** أنشئ مجموعة اسمها `admins`، و Document ID هو رمز حسابك، وأضف حقل `role` قيمته `owner`.
3. حدّث الصفحة، وتقدر بعدها تضيف الفرص وتعدلها وتحذفها.

## وش ينحفظ في الحساب؟
مستند `users/{uid}` فيه: الخطة (`najd_plans_v1`)، والمعدل (`najd_gpa_v1`)، والجدول (`stq_schedule_v1`)، ونتائج الاختبارات (`najd_quiz_v1`)، وخطة المذاكرة (`najd_study_v1`)، ودفتر الأخطاء (`najd_mist_v1`)، واختيارات «وش أسجل الفصل الجاي؟» (`najd_next_v1`).
الأدوات تشتغل بدون حساب وتحفظ في المتصفح. ولما يسجل الطالب دخوله، يتزامن تقدمه بين أجهزته تلقائيًا.

## تنبيهات الدراسة (الإيميل وإشعار الجوال)
بعد ما يسجل الطالب، تطلع له نافذة «خطوة أخيرة: خلّنا نذكّرك». يفعّلها بضغطة، أو يكمل بدونها ونسأله مرة ثانية لما يضيف أول اختبار. يعدّلها متى ما يبي من «حسابي ← تنبيهاتي».

**كيف يعرف الخادم إن عند الطالب اختبار بكرة؟** الجدول وخطة المذاكرة ودفتر الأخطاء محفوظة في حسابه (`users/{uid}.data`). الدالة `reminders` تشتغل الساعة 7 الصبح و7 و8 و9 مساءً بتوقيت الرياض، تقرأ بيانات كل طالب مفعّل التنبيهات، وترسل له في الساعة اللي اختارها:
- **المساء:** اختبار بكرة (مع الفصول اللي باقية عليه)، وواجب بكرة أو بعد يومين، وأسئلة جا وقت مراجعتها.
- **الصبح:** اختبار اليوم، وموعد اليوم، وجلسات مذاكرة اليوم.
- إذا ما عنده شيء، ما يوصله شيء.

الملفات: `assets/js/notify.js` (النافذة والإعدادات)، و`functions/` (الخادم)، و`sw.js` (يعرض إشعار الجوال). اختبار محلي بدون إرسال:
```
cd functions && mkdir -p shared && cp ../assets/js/study-core.js ../assets/js/courses-data.js shared/ && npm ci && npm test
```

**التشغيل (مرة وحدة):**
1. فعّل خطة **Blaze** في مشروع `najd-141`، وحط تنبيه ميزانية (مثلاً 5 دولار). الاستخدام المتوقع داخل الحد المجاني.
2. **مفتاح إشعارات الجوال:** Project settings ← Cloud Messaging ← Web Push certificates ← Generate key pair. انسخ المفتاح العام وحطه في `window.NAJD_PUSH_KEY` في `assets/js/layout.js`. قبل هذي الخطوة، الإيميل يشتغل والجوال يكتب «قريبًا».
3. **كلمة مرور تطبيق** لإيميل الموقع (myaccount.google.com ← الأمان ← التحقق بخطوتين ← كلمات مرور التطبيقات)، وحطها في GitHub ← Settings ← Secrets ← Actions باسم `GMAIL_APP_PASSWORD`.
4. **حساب خدمة للنشر:** Google Cloud ← IAM ← Service accounts ← حساب جديد بهذي الصلاحيات: Cloud Functions Admin، Cloud Run Admin، Cloud Scheduler Admin، Secret Manager Admin، Service Account User، Artifact Registry Administrator، Service Usage Admin، Firebase Admin. نزّل مفتاح JSON وحطه كله في سر باسم `FIREBASE_SERVICE_ACCOUNT`.

بعدها أي تعديل على `functions/` يندمج في `main` ينشر الخادم لحاله (`.github/workflows/functions.yml`)، أو شغّله يدويًا من Actions ← Deploy reminders server ← Run workflow. وجرّبه من زر «جرّب تنبيه الحين» في حسابي.

## تجربة الموقع على جهازك
```
python3 -m http.server 8000
```
وافتح `http://localhost:8000/`.

## الوضع الداكن واللغة
- زر 🌙/☀️ في الهيدر يبدّل بين الوضع الفاتح والداكن، ويتذكر اختيار الزائر. الوضع الأساسي فاتح، والداكن بس لو اختاره الزائر.
- زر EN/ع يبدّل لغة الموقع كامل. الترجمة في `assets/js/i18n.js`: كل سطر نص عربي وترجمته. لو أضفت نص جديد، أضف ترجمته هناك.
- المحتوى اللي تكتبه من لوحة الإدارة (أسماء المنتجات والجهات والشروحات) يظهر مثل ما كتبته.

## صفحات المقررات (`c/<الرمز>.html`)
صفحة ثابتة لكل مقرر عشان قوقل يقرأها. **لا تعدّلها بيدك.** تنبني من:
- `tools/course-template.html`: شكل الصفحة.
- `tools/course-desc.json`: أوصاف المقررات من ملفات الخطط الرسمية للجامعة (عربي وإنجليزي).
- `assets/js/teaching-data.js`: مين يدرّس وش، من صفحة البحث عن الشعب في نظام التسجيل. حدّثه كل فصل.
- بيانات المقررات والخطط في `assets/js/`.

بعد أي تعديل عليها شغّل `python3 tools/build-courses.py` (يبني الصفحات و`sitemap.xml`).

## بعد أي تحديث للملفات
شغّل `python3 tools/set-version.py` عشان يتحدث رقم الإصدار في روابط الملفات، والمتصفحات تجيب النسخة الجديدة على طول. ولو عدّلت بيانات المقررات، شغّل `tools/build-courses.py` قبله.

## الأقسام الجديدة في لوحة الإدارة
- **الاختبارات:** تكتب الأسئلة كنص: السؤال في سطر، وتحته الخيارات، و`*` قبل الإجابة الصحيحة، وسطر فاضي بين الأسئلة. وسطر يبدأ بـ «شرح:» اختياري. الأسئلة محفوظة في `quizData` ويقرأها المشترك فقط (أو الكل لو الاختبار مجاني).
- **التقويم:** مواعيد التقويم الأكاديمي (`calendar`).
- **التقييمات:** التقييم بالأرقام ينشر مباشرة، والتعليق المكتوب يبقى معلّق لين توافق عليه. تقييم واحد لكل طالب لكل مقرر أو عضو.
- **الأعضاء:** أسماء أعضاء هيئة التدريس اللي ينقيّمون (`instructors`).
- **آراء الطلاب:** تظهر في الرئيسية (`testimonials`)، والقسم يختفي لو ما فيه آراء.
