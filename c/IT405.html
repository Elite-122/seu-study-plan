عن المقرر

بناء مواقع وبوابات إلكترونية متغيرة المحتوى: كيف يتعامل المتصفح مع الخادم، والبرمجة من جهة الخادم بلغة PHP، واستقبال النماذج، وربط الموقع بقاعدة بيانات MySQL، وتسجيل دخول المستخدمين، وأساسيات حماية الموقع. وينتهي بمشروع بوابة فيها تسجيل ومحتوى يُدار من لوحة تحكم.

Building dynamic websites and portals: how the browser talks to the server, server-side programming in PHP, handling forms, connecting a site to a MySQL database, user login, and basic web security. It ends with a portal project with registration and content managed from an admin panel.

ما لقينا وصف رسمي لهذا المقرر في ملفات الجامعة، فكتبناه من الكتب والمراجع المعتمدة في المادة: Larry Ullman, PHP and MySQL for Dynamic Web Sites، Robin Nixon, Learning PHP, MySQL & JavaScript، Luke Welling & Laura Thomson, PHP and MySQL Web Development

No official description in the university files, so we wrote it from the standard references for the subject: Larry Ullman, PHP and MySQL for Dynamic Web Sites, Robin Nixon, Learning PHP, MySQL & JavaScript, Luke Welling & Laura Thomson, PHP and MySQL Web Development.
