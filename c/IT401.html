عن المقرر

مدخل للبرمجة لطلاب الأعمال: كيف تحوّل مشكلة عمل إلى خطوات منطقية (خوارزمية)، ثم تكتبها برنامجًا. يغطي المتغيرات وأنواع البيانات، والشروط والتكرار، والدوال، والقوائم والملفات، وبناء برامج صغيرة تعالج بيانات الأعمال مثل الحسابات والتقارير. وهو الأساس لمقرر قواعد البيانات بعده.

An introduction to programming for business students: turning a business problem into logical steps (an algorithm) and writing it as a program. Covers variables and data types, conditions and loops, functions, lists and files, and small programs that process business data such as calculations and reports. It prepares for the databases course that follows.

ما لقينا وصف رسمي لهذا المقرر في ملفات الجامعة، فكتبناه من الكتب والمراجع المعتمدة في المادة: Tony Gaddis, Starting Out with Python، Charles Severance, Python for Everybody، Diane Zak, Programming with Microsoft Visual Basic

No official description in the university files, so we wrote it from the standard references for the subject: Tony Gaddis, Starting Out with Python, Charles Severance, Python for Everybody, Diane Zak, Programming with Microsoft Visual Basic.
