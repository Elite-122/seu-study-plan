# نظام التصميم: أكاديمية نجد

المرجع لأي تعديل أو صفحة جديدة في الموقع. القيم كلها هنا مأخوذة من الكود نفسه (`assets/css/najd.css`). لو تغيّر الكود، حدّث هذا الملف معه.

دليل الهوية الأصلي (الألوان والشعار والأسلوب) هو المصدر للقرارات البصرية، وهذا الملف يوضح كيف تطبّقت في الكود.

---

## 1. القواعد الأساسية

1. **لا تكتب لون أو حجم بيدك.** استخدم المتغيرات (`var(--…)`). المتغيرات هي اللي تخلي الوضع الغامق يشتغل بدون سطور إضافية.
2. **قبل ما تسوي عنصر جديد، شوف القسم 4.** إذا فيه عنصر يقارب اللي تبيه، استخدمه وأضف عليه، لا تنسخه باسم جديد.
3. **كل التنسيق داخل `#najd`.** المتغيرات معرّفة على `#najd`، فأي عنصر برا هذا الغلاف ما يشوفها.
4. **العربي أولًا (من اليمين لليسار).** استخدم `margin-inline-start` و`padding-inline-end` بدل left وright، عشان النسخة الإنجليزية تنقلب صح.
5. **الحالة بالخصائص، مو بأسماء الكلاسات.** الأزرار المختارة `aria-pressed="true"`، والتبويب المفتوح `aria-selected="true"`، والحقل الغلط `aria-invalid="true"`. التنسيق يقرأ هذي الخصائص، وقارئ الشاشة يقرأها بعد.

## 4. العناصر المشتركة

كلها في آخر `najd.css`، والأسماء تبدأ بـ `nj-`.

### 4.1 الزر `nj-btn`

| النوع | الكلاس | متى |
|---|---|---|
| أساسي | `nj-btn nj-btn-fill` | الإجراء الرئيسي في الشاشة. واحد بس لكل مجموعة |
| ثانوي | `nj-btn nj-btn-line` | إجراء ثاني جنب الأساسي |
| على خلفية غامقة | `nj-btn-white` / `nj-btn-ghost` | داخل الهيدر الملوّن والأقسام الغامقة |
| صغير | يضاف `nj-btn-sm` | داخل البطاقات والصفوف |
| مقفل | يضاف `is-locked` | محتوى يحتاج اشتراك |

- **الحالات:** عادي، تمرير، تركيز (حلقة `--teal`)، معطّل (`disabled`، يصير شفاف ومؤشر انتظار).
- **أيقونة داخل الزر:** `'<button class="nj-btn nj-btn-fill">' + Najd.icon('bell') + 'النص</button>'`. الأيقونة تاخذ لون النص تلقائيًا.

### 4.2 البطاقة `nj-card`

الحاوية الأساسية لأي محتوى: خلفية `--card` وحد `--line` وزاوية `--r` وظل `--shadow`. البطاقات الخاصة (منتج، شرح، اختبار) تضيف كلاسها جنب `nj-card` ولا تعيد كتابة الخلفية والحد.

### 4.3 زر الاختيار `nj-chip` داخل `nj-chips`

للفلاتر: يتفعل واحد أو أكثر. الحالة بـ `aria-pressed`.

```html
<div class="nj-chips" role="group" aria-label="المقرر">
  <button type="button" class="nj-chip" aria-pressed="true">الكل <small>12</small></button>
  <button type="button" class="nj-chip" aria-pressed="false">ACCT101</button>
</div>
```

| إضافة | التأثير |
|---|---|
| `<small>` داخله | عداد صغير |
| `is-accent` | حد ملوّن للفت الانتباه (مثل «المفتوح لك») |
| `is-soft` | المختار بخلفية خفيفة بدل الممتلئة (التخصصات في الخطة) |

**مستخدم في:** الشروحات، التقويم، تجارب الطلاب، الخطة.

### 4.4 الخيار المقطّع `nj-seg`

خيار واحد من خيارات متساوية العرض، مثل: النوع، المدة، لون الجدول، ووش يطلع في الملف.

```html
<div class="nj-seg" role="group" aria-label="النوع">
  <button type="button" aria-pressed="true">ملخصات</button>
  <button type="button" aria-pressed="false">شروحات</button>
</div>
```

الأزرار تتوزع تلقائيًا وتنزل سطر جديد إذا ضاقت الشاشة. **مستخدم في:** الجدول الدراسي، ولوحة الإدارة (تفعيل اشتراك).

### 4.5 التبويبات `nj-tabs` و`nj-tab`

للتنقل بين أقسام في نفس الصفحة. الحالة بـ `aria-selected`، والحاوية `role="tablist"`، وكل زر `role="tab"`. على الجوال، كل تبويبين في سطر. **مستخدم في:** تجارب الطلاب، ولوحة الإدارة.

### 4.6 الشارة `nj-tag`

كلمة قصيرة تصف حالة أو تصنيف. ما تنضغط.

| الكلاس | الشكل | مثال |
|---|---|---|
| `nj-tag` | خلفية خفيفة | مجاني |
| `nj-tag is-paid` | ممتلئة غامقة | للمشتركين |
| `nj-tag is-ok` | أخضر | مشترك، مؤكد |
| `nj-tag is-err` | أحمر | منتهي |
| `nj-tag is-warn` | أصفر | قريب |
| `nj-tag is-muted` | محايدة بحد | تصنيف، «غير مشترك» |
| `is-md` | أكبر قليلًا | داخل صفوف الحساب |
| `is-square` | زوايا بدل حبة دواء | قوائم التخصصات |

### 4.7 الحقل `nj-input` والغلاف `nj-field`

حقل منفرد:

```html
<input class="nj-input" type="search" placeholder="ابحث…" aria-label="بحث">
<select class="nj-input is-sm is-raised">…</select>
<textarea class="nj-input"></textarea>
```

| إضافة | التأثير |
|---|---|
| `is-sm` | ارتفاع 44px وخط أصغر، للصفوف الكثيفة |
| `is-raised` | خلفية `--surface`، للحقل اللي فوق خلفية `--bg` |
| `aria-invalid="true"` | حد وهالة حمراء |
| `disabled` | شفاف ومقفل |

مجموعة حقول بعناوين تستخدم الغلاف، وأي حقل داخله يتنسق تلقائيًا بدون كلاس:

```html
<div class="nj-field">
  <label for="mail">بريد الطالب *</label>
  <input id="mail" type="email">
  <small>بريد حسابه في أكاديمية نجد.</small>
</div>
```

**مستخدم في:** لوحة الإدارة، والدخول والتسجيل، والجدول، والمعدل، والتدريب التعاوني، وتجارب الطلاب، والحساب، والرئيسية.

### 4.8 الحالة الفاضية `nj-empty`

لما ما يكون فيه محتوى، أو صار خطأ في التحميل:

```js
box.innerHTML = '<div class="nj-card nj-empty"><span class="nj-icon-xl">' + Najd.icon('book') + '</span>'
  + '<b>ما فيه شروحات منشورة حاليًا</b><p>نضيف الشروحات أول بأول، ارجع لنا قريب.</p></div>';
```

- النسخة السطرية `nj-empty is-inline`: سطر نص بس داخل نموذج.
- أيقونة الخطأ في الاتصال: `offline`.

### 4.9 الأيقونات `Najd.icon(name, cls)`

أيقونات مرسومة بخط واحد (عرض 1.7) بلون الهوية. لا تستخدم الإيموجي في الواجهة.

| الاسم | | الاسم | | الاسم | |
|---|---|---|---|---|---|
| `plans` | الخطط | `schedule` | الجدول | `gpa` | المعدل |
| `calendar` | التقويم | `lessons` | الشروحات | `quiz` | الاختبارات |
| `ratings` | التقييم (نجمة) | `coop` | التدريب | `store` | المتجر |
| `bell` | تنبيه | `lock` | قفل | `pin` | موقع |
| `search` | بحث | `offline` | لا يوجد اتصال | `book` | كتاب |
| `file` | ملف | `play` | فيديو | `mail` | بريد |
| `check` | تم | `bulb` | فكرة | `target` | هدف |
| `bolt` | سريع | `cloud` | مزامنة | `user` | شخص |
| `compass` `coins` `cart` `ledger` | أيقونات التخصصات الأربعة | | | | |

- **الحجم:** يتبع حجم الخط (1.25em). كبّرها بكلاس من الصفحة إذا احتجت.
- **اللون:** `--teal`. داخل الأزرار تاخذ لون النص.
- **حاوية كبيرة:** `nj-icon-xl` (مربع 64px بخلفية `--tint`) للحالة الفاضية والبطاقات البارزة.
- **أيقونة جديدة:** أضف مسارها في `IC` داخل `layout.js`. لوحة الرسم 24×24، وبدون تعبئة.

> **انتبه:** `nj-ic` اسم زر الوضع الغامق في الهيدر. الأيقونات اسمها `nj-icon`، لا تخلط بينهم.

### 4.10 التنبيه المنبثق والنافذة

- **`Najd.toast('النص')`:** رسالة قصيرة أسفل الشاشة تختفي بعد 3 ثواني، وقارئ الشاشة يقرأها. للتأكيدات والأخطاء البسيطة.
- **`nj-modal`:** نافذة فوق الصفحة (مستخدمة لتشغيل الفيديو). تقفل بـ Esc أو بالضغط برا، والتركيز ينتقل لزر الإغلاق.

## 5. إمكانية الوصول

- **التركيز بالكيبورد:** كل الروابط والأزرار والحقول عليها حلقة `--teal` واضحة. لا تحط `outline:none` بدون بديل.
- **التباين:** النص 4.5:1 على الأقل. المتغيرات في القسم 3.1 محسوبة على هذا.
- **أهداف اللمس:** 44px على الأقل للأزرار والحقول.
- **الحالات:** بخصائص ARIA (`aria-pressed`، `aria-selected`، `aria-invalid`، `aria-live` للرسائل)، مو بالألوان بس.
- **الصور والأيقونات:** الزخرفية تاخذ `aria-hidden="true"` (الدالة `Najd.icon` تحطها تلقائيًا).

---

## 6. الوضع الغامق

- يتفعل بـ `data-theme="dark"` على `<html>`، والمتغيرات تتبدل تلقائيًا.
- **إذا استخدمت المتغيرات ما تحتاج تكتب شي للغامق.** إذا اضطريت لقيمة ثابتة، أضف لها سطر `html[data-theme="dark"] #najd …` في `najd.css`.
- لما يتبدل الوضع، الصفحة تطلق حدث `najd:theme` لأي سكربت يحتاج يعيد الرسم.

---

## 7. الترجمة والاتجاه

- النص العربي يتكتب مباشرة في الصفحة، والترجمة في `assets/js/i18n.js` داخل `DICT`. النص اللي فيه أرقام يروح في `TPL` ويُكتب `{n}` مكان الرقم.
- **النص اللي يكتبه المشرف** (عناوين الشروحات، أسماء المنتجات) ياخذ `data-no-i18n` عشان ما يترجمه الموقع كلمة كلمة.
- **التواريخ:** حطها في `<span data-no-i18n>` منفصل عن الكلمة اللي قبلها.

## 8. استثناءات معروفة

| الموضوع | السبب |
|---|---|
| رسم الصور والـ PDF (خلفية الجوال، الجدول المطبوع، تقرير الخطة) فيها ألوان مكتوبة | الرسم يصير على canvas وما يقرأ متغيرات CSS. الألوان نفسها مأخوذة من الهوية |
| ألوان المواد في الجدول (`PAL`) وألوان رموز المقررات في الخطة (`PFX`) | لوحات تصنيف داخل السكربت، وتُستخدم في الرسم بعد |
| أداة اختيار التاريخ (flatpickr) | تنفتح برا `#najd`، فلها ألوان خاصة في `najd.css` |
| `padding` فيه قيم قديمة مكتوبة | ما تغيّرت عشان ما يتحرك التصميم. أي تعديل جديد يستخدم `--sp-*` |
| `college-plans.html` | صفحة قديمة مستقلة، خارج النظام |

## 9. قائمة قبل ما تنشر صفحة أو تعديل

- [ ] ما فيه ألوان أو أحجام خط أو زوايا مكتوبة باليد، كلها `var(--…)`
- [ ] استخدمت العناصر المشتركة (القسم 4) بدل نسخها
- [ ] الصفحة تنقرأ في الوضع الغامق
- [ ] ما فيه تمرير أفقي على عرض 360px
- [ ] كل زر وحقل يوصله الكيبورد وتبان حلقة التركيز
- [ ] النصوص الجديدة لها ترجمة في `i18n.js`
- [ ] شغّلت `python3 tools/set-version.py` بعد تعديل CSS أو JS
