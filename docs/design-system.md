# نظام التصميم: أكاديمية نجد

المرجع لأي تعديل أو صفحة جديدة في الموقع. القيم كلها هنا مأخوذة من الكود نفسه (`assets/css/najd.css`). لو تغيّر الكود، حدّث هذا الملف معه.

دليل الهوية الأصلي (الألوان والشعار والأسلوب) هو المصدر للقرارات البصرية، وهذا الملف يوضح كيف تطبّقت في الكود.

---

## 1. القواعد الأساسية

1. **لا تكتب لون أو حجم بيدك.** استخدم المتغيرات (`var(--…)`). المتغيرات هي اللي تخلي الوضع الغامق يشتغل بدون سطور إضافية.
2. **قبل ما تسوي عنصر جديد، شوف القسم 4.** إذا فيه عنصر يقارب اللي تبيه، استخدمه وأضف عليه، لا تنسخه باسم جديد.
3. **كل التنسيق داخل `#najd`.** المتغيرات معرّفة على `#najd`، فأي عنصر برا هذا الغلاف ما يشوفها.
4. **العربي أولًا (من اليمين لليسار).** استخدم `margin-inline-start` و`padding-inline-end` بدل left وright، عشان النسخة الإنجليزية تنقلب صح.
5. **الحالة بالخصائص، مو بأسماء الكلاسات.** الأزرار المختارة `aria-pressed="true"`، والتبويب المفتوح `aria-selected="true"`، والحقل الغلط `aria-invalid="true"`. التنسيق يقرأ هذي الخصائص، وقارئ الشاشة يقرأها بعد.
6. **لا تبدأ اسم كلاس أو id بـ `ad-` أو `ads-` أو `sponsor` أو `banner-`.** إضافات منع الإعلانات تخفي أي عنصر بهالأسماء (مثل `#ad-panel` و`.ad-row`)، فتطلع الصفحة فاضية عند اللي مركّبها. لوحة الإدارة تستخدم `cp-`.

## 4. العناصر المشتركة

كلها في آخر `najd.css`، والأسماء تبدأ بـ `nj-`.

### 4.1 الزر `nj-btn`

| النوع | الكلاس | متى |
|---|---|---|
| أساسي | `nj-btn nj-btn-fill` | الإجراء الرئيسي في الشاشة. واحد بس لكل مجموعة |
| ثانوي | `nj-btn nj-btn-line` | إجراء ثاني جنب الأساسي |
| على خلفية غامقة | `nj-btn-white` / `nj-btn-ghost` | داخل الهيدر الملوّن والأقسام الغامقة |
| صغير | يضاف `nj-btn-sm` | داخل البطاقات والصفوف |
| مقفل | يضاف `is-locked` | محتوى يحتاج اشتراك |

- **الحالات:** عادي، تمرير، تركيز (حلقة `--teal`)، معطّل (`disabled`، يصير شفاف ومؤشر انتظار).
- **أيقونة داخل الزر:** `'<button class="nj-btn nj-btn-fill">' + Najd.icon('bell') + 'النص</button>'`. الأيقونة تاخذ لون النص تلقائيًا.

### 4.2 البطاقة `nj-card`

الحاوية الأساسية لأي محتوى: خلفية `--card` وحد `--line` وزاوية `--r` وظل `--shadow`. البطاقات الخاصة (منتج، شرح، اختبار) تضيف كلاسها جنب `nj-card` ولا تعيد كتابة الخلفية والحد.

### 4.3 زر الاختيار `nj-chip` داخل `nj-chips`

للفلاتر: يتفعل واحد أو أكثر. الحالة بـ `aria-pressed`.

```html
<div class="nj-chips" role="group" aria-label="المقرر">
  <button type="button" class="nj-chip" aria-pressed="true">الكل <small>12</small></button>
  <button type="button" class="nj-chip" aria-pressed="false">ACCT101</button>
</div>
```

| إضافة | التأثير |
|---|---|
| `<small>` داخله | عداد صغير |
| `is-accent` | حد ملوّن للفت الانتباه (مثل «المفتوح لك») |
| `is-soft` | المختار بخلفية خفيفة بدل الممتلئة (التخصصات في الخطة) |

**مستخدم في:** الشروحات، التقويم، تجارب الطلاب، الخطة.

### 4.4 الخيار المقطّع `nj-seg`

خيار واحد من خيارات متساوية العرض، مثل: النوع، المدة، لون الجدول، ووش يطلع في الملف.

```html
<div class="nj-seg" role="group" aria-label="النوع">
  <button type="button" aria-pressed="true">ملخصات</button>
  <button type="button" aria-pressed="false">شروحات</button>
</div>
```

الأزرار تتوزع تلقائيًا وتنزل سطر جديد إذا ضاقت الشاشة. **مستخدم في:** الجدول الدراسي، ولوحة الإدارة (تفعيل اشتراك).

### 4.5 التبويبات `nj-tabs` و`nj-tab`

للتنقل بين أقسام في نفس الصفحة. الحالة بـ `aria-selected`، والحاوية `role="tablist"`، وكل زر `role="tab"`. على الجوال، كل تبويبين في سطر. **مستخدم في:** تجارب الطلاب، ولوحة الإدارة.

### 4.6 الشارة `nj-tag`

كلمة قصيرة تصف حالة أو تصنيف. ما تنضغط.

| الكلاس | الشكل | مثال |
|---|---|---|
| `nj-tag` | خلفية خفيفة | مجاني |
| `nj-tag is-paid` | ممتلئة غامقة | للمشتركين |
| `nj-tag is-ok` | أخضر | مشترك، مؤكد |
| `nj-tag is-err` | أحمر | منتهي |
| `nj-tag is-warn` | أصفر | قريب |
| `nj-tag is-muted` | محايدة بحد | تصنيف، «غير مشترك» |
| `is-md` | أكبر قليلًا | داخل صفوف الحساب |
| `is-square` | زوايا بدل حبة دواء | قوائم التخصصات |

### 4.7 الحقل `nj-input` والغلاف `nj-field`

حقل منفرد:

```html
<input class="nj-input" type="search" placeholder="ابحث…" aria-label="بحث">
<select class="nj-input is-sm is-raised">…</select>
<textarea class="nj-input"></textarea>
```

| إضافة | التأثير |
|---|---|
| `is-sm` | ارتفاع 44px وخط أصغر، للصفوف الكثيفة |
| `is-raised` | خلفية `--surface`، للحقل اللي فوق خلفية `--bg` |
| `aria-invalid="true"` | حد وهالة حمراء |
| `disabled` | شفاف ومقفل |

مجموعة حقول بعناوين تستخدم الغلاف، وأي حقل داخله يتنسق تلقائيًا بدون كلاس:

```html
<div class="nj-field">
  <label for="mail">بريد الطالب *</label>
  <input id="mail" type="email">
  <small>بريد حسابه في أكاديمية نجد.</small>
</div>
```

**مستخدم في:** لوحة الإدارة، والدخول والتسجيل، والجدول، والمعدل، والتدريب التعاوني، وتجارب الطلاب، والحساب، والرئيسية.

### 4.8 الحالة الفاضية `nj-empty`

لما ما يكون فيه محتوى، أو صار خطأ في التحميل:

```js
box.innerHTML = '<div class="nj-card nj-empty"><span class="nj-icon-xl">' + Najd.icon('book') + '</span>'
  + '<b>ما فيه شروحات منشورة حاليًا</b><p>نضيف الشروحات أول بأول، ارجع لنا قريب.</p></div>';
```

- النسخة السطرية `nj-empty is-inline`: سطر نص بس داخل نموذج.
- أيقونة الخطأ في الاتصال: `offline`.

### 4.9 الأيقونات `Najd.icon(name, cls)`

أيقونات مرسومة بخط واحد (عرض 1.7) بلون الهوية. لا تستخدم الإيموجي في الواجهة.

| الاسم | | الاسم | | الاسم | |
|---|---|---|---|---|---|
| `plans` | الخطط | `schedule` | الجدول | `gpa` | المعدل |
| `calendar` | التقويم | `lessons` | الشروحات | `quiz` | الاختبارات |
| `ratings` | التقييم (نجمة) | `coop` | التدريب | `store` | المتجر |
| `bell` | تنبيه | `lock` | قفل | `pin` | موقع |
| `search` | بحث | `offline` | لا يوجد اتصال | `book` | كتاب |
| `file` | ملف | `play` | فيديو | `mail` | بريد |
| `check` | تم | `bulb` | فكرة | `target` | هدف |
| `bolt` | سريع | `cloud` | مزامنة | `user` | شخص |
| `compass` `coins` `cart` `ledger` | أيقونات التخصصات الأربعة | | | | |

- **الحجم:** يتبع حجم الخط (1.25em). كبّرها بكلاس من الصفحة إذا احتجت.
- **اللون:** `--teal`. داخل الأزرار تاخذ لون النص.
- **حاوية كبيرة:** `nj-icon-xl` (مربع 64px بخلفية `--tint`) للحالة الفاضية والبطاقات البارزة.
- **أيقونة جديدة:** أضف مسارها في `IC` داخل `layout.js`. لوحة الرسم 24×24، وبدون تعبئة.

> **انتبه:** `nj-ic` اسم زر الوضع الغامق في الهيدر. الأيقونات اسمها `nj-icon`، لا تخلط بينهم.

### 4.10 التنبيه المنبثق والنافذة

- **`Najd.toast('النص')`:** رسالة قصيرة أسفل الشاشة تختفي بعد 3 ثواني، وقارئ الشاشة يقرأها. للتأكيدات والأخطاء البسيطة.
- **`nj-modal`:** نافذة فوق الصفحة (مستخدمة لتشغيل الفيديو). تقفل بـ Esc أو بالضغط برا، والتركيز ينتقل لزر الإغلاق.

### 4.11 البحث وتنبيه التطبيق والزائر
- **البحث (`nj-sx`):** يفتح من زر البحث في الهيدر، أو من الكيبورد بـ `/` أو Ctrl+K، أو من الكود بـ `Najd.search()`. يبحث في الأدوات والمقررات (`NAJD_COURSES`) وأعضاء هيئة التدريس (`NAJD_FACULTY`)، ويحمّل ملفاتهم أول ما ينفتح. يتجاهل الهمزات والتاء المربوطة والتشكيل.
- **تنبيه التثبيت (`nj-pwa`) وخطواته (`nj-sheet`):** يطلع مرة وحدة في الجوال. لو تفاعل معه الطالب ما يرجع. ويقدر يفتحه بعدين من رابط «ثبّت التطبيق» في الفوتر، أو من الكود بـ `Najd.install()`.
- **صفحات الزائر:** `data-auth="guest"` على `#najd` تخلي الأداة تشتغل بدون حساب، ويطلع شريط `nj-guestbar` يدعوه يسجّل. أما `data-auth="required"` فيقفل الصفحة لين يسجّل دخول.
- **التطبيق:** `manifest.webmanifest` و`sw.js` في جذر الموقع. قائمة الملفات المحفوظة في `sw.js` يحدّثها `tools/set-version.py` تلقائيًا. وأي صفحة جديدة لازم يكون في رأسها رابط `manifest`، و`viewport-fit=cover` في وسم viewport.

### 4.12 الشريط السفلي في التطبيق (`nj-tabbar`)
- يبنيه `layout.js` في كل صفحة فيها هيدر (ما عدا الإدارة): الرئيسية، خطتي، جدولي، المعدل، المزيد.
- **يظهر بس** لما الموقع مفتوح كتطبيق مثبّت (`html.is-app`) وعرض الشاشة 760px أو أقل. في المتصفح مخفي.
- الصفحة الحالية عليها `aria-current="page"`. «المزيد» يفتح نفس قائمة الجوال (`nj-drawer`) وعليه `aria-expanded`.
- في وضع التطبيق، الفوتر والتنبيه المنبثق ينزاحون فوق الشريط، والشريط يحسب مسافة زر الهوم في الآيفون (`env(safe-area-inset-bottom)`).

### 4.13 الضغط واللمس
- `nj-btn` يصغر شوي لحظة الضغط، و`nj-chip` و`nj-ic` يتلونون بـ `--tint`. أي زر جديد مهم يمشي على نفس الشي.
- الروابط النصية الصغيرة (الفوتر، مسار الصفحة، «نسيت كلمة المرور؟») تكبر مساحة لمسها لـ 44px في الأجهزة اللمسية (`@media (pointer:coarse)`) بدون ما يتغير شكلها.
- `nj-open` (علامة صح خضراء) للأدوات اللي تشتغل بدون حساب، و`nj-lock` للي تحتاج دخول.

### 4.14 صفحة طويلة بتبويبات، وشريط نتيجة صغير
- **التبويبات داخل الصفحة** (مثال: الجدول): `nj-tabs` بأزرار `role="tab"` ولوحات `role="tabpanel"`، والمخفية عليها `hidden`. التبويبات تلزق تحت الهيدر (`position:sticky`)، والأسهم في الكيبورد تتنقل بينها، والرابط ياخذ `#ex` أو `#save` عشان يفتح على التبويب. تحت كل لوحة زر «التالي».
- **شريط النتيجة الصغير** (مثال: `gp-mini` في المعدل): يطلع في الجوال بس لما الرقم الأساسي يطلع فوق الشاشة، ويختفي عند الفوتر. عليه `aria-hidden="true"` لأن النتيجة الأصلية مقروءة. في التطبيق ينزاح فوق الشريط السفلي.

### 4.15 «لوحتي» في الرئيسية (`hm-dash`)
- تطلع للمسجّل، أو للزائر اللي عنده بيانات محفوظة في جهازه (جدول أو اختبارات أو خطة أو معدل)، وتخفي الواجهة التسويقية (`#najd.has-dash .hm-hero`).
- أربع بطاقات (`dsh-card`): محاضرات اليوم (من `stq_schedule_v1`، والخانات المتتالية لنفس المادة محاضرة وحدة، مع «الحين» و«بعد كذا دقيقة» و«التالية»)، وأقرب اختبار (يفتح `schedule.html#ex`)، وتقدم الخطة (`najd_plans_v1`)، والمعدل المتوقع (`najd_gpa_v1`).
- البطاقة الفاضية (`dsh-empty`) تشرح وش يسوي الطالب، وفيها زر يوديه للأداة.
- النصوص تنبني بالكود بالعربي والإنجليزي (`data-no-i18n` على القسم). الأوقات أرقامها معزولة من اليسار لليمين و«م/ص» برّاها.
- تتحدث مع أي مزامنة أو تعديل، وكل دقيقة.

### 4.16 صفحة المقرر (`c/<الرمز>.html`)
- ثابتة لكل مقرر، وفيها `<base href="../">` عشان كل الروابط والملفات تبدأ من جذر الموقع. الروابط الداخلية للأقسام تكون `c/CODE.html#about` مو `#about` لحالها.
- الترتيب: الرأس (الرمز، الاسم، الساعات، التقييم، الصعوبة، الشعب)، وبعده الأقسام: عن المقرر (الوصف وسلسلة قبلها/هي/تفتح لك)، الشروحات، تجارب الطلاب، مين يدرّسه. وعلى الجنب: حالتها في خطة الطالب وأزرار «علّمها في خطتي» و«أضفها لجدولي» و«قيّم المقرر».
- الوصف العربي ترجمة للوصف الرسمي، والإنجليزي الرسمي نفسه يطلع في النسخة الإنجليزية.

### 4.17 خطة المذاكرة ودفتر الأخطاء و«وش أسجل الفصل الجاي؟»
- **خطة المذاكرة (`study.html`):** تبويبات اليوم / الأسبوع / اختباراتي / أوقاتي. الجلسات يولدها `study-core.js` من المحفوظ بس، عشان تطلع نفسها في «لوحتي». أي تغيير على طريقة التوزيع يكون في هذا الملف.
- **دفتر الأخطاء:** السؤال الغلط يرجع بعد يوم، ثم ٣، ثم ٧، لين ينحل صح ٣ مرات. يتعرف على السؤال من بصمة نصه، فلو تغير نص السؤال في لوحة الإدارة يعتبر سؤال جديد.
- **«وش أسجل الفصل الجاي؟» (`next-term.html`):** المفتوح من الخطة، مرتب: المتأخر عن المستوى، ثم اللي يفتح مواد أكثر. ما يحط أكثر من مادتين صعبة (٣.٨ فأعلى من ٥). موعد التسجيل من التقويم (النوع «التسجيل»)، ويطلع في «لوحتي» قبله بأسبوعين.

### 4.18 التقويم الأكاديمي (`calendar.html`)
- **التبويبات** (`ac-tabs`): الأول والثاني والصيفي، والفصل الحالي عليه شارة «الحين». الأسهم و Home و End تتنقل بينها، والتبويب المختار وحده يدخله Tab.
- **رحلة الفصل** (`ac-trip`): بطاقة غامقة فيها «الأسبوع N من M» وكم يوم باقي، وشريط من بداية الدراسة لإغلاق الفصل: الاختبارات مرتفعات حمراء، والإجازات أخضر، واللي مضى رملي، واليوم نقطة. البداية من جهة القراءة (يمين بالعربي، يسار بالإنجليزي). اللي جاري الحين (اختبارات أو إجازة) يطلع تحته في سطر «الحين:».
- **مفتوح الحين** (`ao`): الطلبات والتسجيل المفتوحة بس (مو الاختبارات ولا الإجازات)، مرتبة بالأقرب قفلًا، والرقم أحمر لما يبقى ٣ أيام أو أقل.
- **سطر الموعد** (`ai`): التاريخ، ونقطة بلون النوع على خط، والعنوان والمدة، وشارة الحالة (مفتوح، جاري، بعد كذا، اليوم، انتهى)، وزر 44px يضيفه لتقويم الجوال. اللي انتهى ينطوي تحت «اللي انتهى (N)» ولونه أخف بدون شفافية (عشان يبقى التباين فوق 4.5).
- **ألوان الأنواع:** اختبارات `#B0625A`، إجازات `#6E8F5E`، تسجيل ورسوم `#4F7CA8`، طلبات `#B08A4E`، بداية ونهاية `--teal`، ومن نجد `#7A5BA6`. اللون مو الدليل الوحيد: كل نوع له اسم في الفلتر.
- **إعلان العمادة** (`ac-ann`): شارة رملية «مدّدته العمادة» أو «عدّلته العمادة» تفتح الإعلان، وتحتها الموعد اللي كان في التقويم. لو الإعلان يأكد الموعد بس، الشارة فاتحة «إعلان العمادة». الشارة 28px بس منطقة الضغط 44px.

### 4.19 دليل الطالب (`guide.html`)
- **فوق:** بحث يتجاهل الهمزات والتاء المربوطة، وأسئلة سريعة، وفهرس 8 بطاقات.
- **القسم** (`gd-sec`): رقم، وعنوان، و«الخلاصة» في صندوق رملي، ومواعيده من التقويم الرسمي، وأداة لو له (كم أقدر أغيب، مقارنة الانسحاب والاعتذار والتأجيل، عداد الإنذارات)، وبعدها أسئلة تنفتح (`details`).
- **المصدر** تحت كل جواب: شارة صغيرة تفتح الملف الرسمي، ومنطقة ضغطها 44px.
- **رابط لسؤال معيّن:** `guide.html#s3-2` يفتحه.

### 4.20 المقررات (`courses.html`)
- **بطاقة المقرر** (`cc`): الرمز، والاسم، والوصف في سطرين، والساعات والمتطلب، ومتوسط التقييم، وكم عضو يدرّسه، والحد الملوّن حسب القسم. البطاقة كلها رابط لصفحة المقرر.
- **«مقرراتك»:** بطاقة المستوى (غامقة) وبعدها: المتأخر عليك، ومقررات مستواك اللي باقية، والفصل الجاي، واللي خلّصتها مطوية.

## 5. إمكانية الوصول

- **التركيز بالكيبورد:** كل الروابط والأزرار والحقول عليها حلقة `--teal` واضحة. لا تحط `outline:none` بدون بديل.
- **التباين:** النص 4.5:1 على الأقل. المتغيرات في القسم 3.1 محسوبة على هذا.
- **أهداف اللمس:** 44px على الأقل للأزرار والحقول والرقائق وأزرار الأيقونات، وحتى الروابط النصية في الأجهزة اللمسية (4.13).
- **الجوالات الضيقة:** كل صفحة لازم تركب على عرض 320px بدون سحب يمين ويسار. تحت 400px الشعار يصغر، وتحت 350px زر اللغة ينتقل للقائمة.
- **الحالات:** بخصائص ARIA (`aria-pressed`، `aria-selected`، `aria-invalid`، `aria-live` للرسائل)، مو بالألوان بس.
- **الصور والأيقونات:** الزخرفية تاخذ `aria-hidden="true"` (الدالة `Najd.icon` تحطها تلقائيًا).

## 6. الوضع الغامق

- يتفعل بـ `data-theme="dark"` على `<html>`، والمتغيرات تتبدل تلقائيًا.
- **إذا استخدمت المتغيرات ما تحتاج تكتب شي للغامق.** إذا اضطريت لقيمة ثابتة، أضف لها سطر `html[data-theme="dark"] #najd …` في `najd.css`.
- لما يتبدل الوضع، الصفحة تطلق حدث `najd:theme` لأي سكربت يحتاج يعيد الرسم.

## 7. الترجمة والاتجاه

- النص العربي يتكتب مباشرة في الصفحة، والترجمة في `assets/js/i18n.js` داخل `DICT`. النص اللي فيه أرقام يروح في `TPL` ويُكتب `{n}` مكان الرقم.
- **النص اللي يكتبه المشرف** (عناوين الشروحات، أسماء المنتجات) ياخذ `data-no-i18n` عشان ما يترجمه الموقع كلمة كلمة.
- **التواريخ:** حطها في `<span data-no-i18n>` منفصل عن الكلمة اللي قبلها.
