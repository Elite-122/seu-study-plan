# إخفاء حساب GitHub عن المستخدمين

ملاحظات محفوظة للرجوع لها وقت الحاجة. ما نفّذنا أي طريقة للحين.

## هل يقدرون يلقون الحساب؟

- **بحث «نجد» بس في GitHub:** صعب. اسم المستودع `seu-study-plan`، وكلمة «نجد» عامة وتطلع لها نتائج كثير.
- **اللي يدور بقصد يقدر يلقاه:**
  - **البحث في الكود داخل GitHub** (يحتاج تسجيل دخول): البحث عن `najdacdemy` أو «أكاديمية نجد» يطلع المستودع مباشرة، لأن الدومين والاسم مكتوبين في ملفاته (README وملف الدومين CNAME).
  - **قوقل:** ممكن يأرشف المستودع مع الوقت، ويطلع لو أحد بحث عن «أكاديمية نجد github».
- **الموقع نفسه:** ما فيه أي رابط للحساب. ملفات دليل التدريب في تطبيق الآيفون تنزل من عامل Cloudflare (`najd-files`)، مو من GitHub.

**الخلاصة:** الطالب العادي ما راح يوصل له، بس أي أحد يبحث بقصد يقدر يلقاه. عشان تقفل الباب كامل، استخدم الطريقة ١ أو ٢ تحت.

## وش يتأثر لو صار المستودع خاص

| الشي | وهو عام | لو صار خاص |
|---|---|---|
| الموقع (GitHub Pages) | مجاني | يتوقف إلا مع GitHub Pro (٤ دولار في الشهر) |
| تذكيرات المذاكرة (GitHub Actions) | دقايق بدون حد | الحد ٢٠٠٠ دقيقة في الشهر. التذكيرات تقريبًا ٧٦ تشغيلة في اليوم، يعني ~٢٣٠٠ دقيقة، فتوقف قبل آخر الشهر. مع Pro يصير الحد ٣٠٠٠ ويكفي |
| البوت وعامل الملفات (Cloudflare) | — | ما يتأثرون، ياخذون من الموقع مو من GitHub |

## الطرق

### ١) GitHub Pro بـ ٤ دولار في الشهر (الأسهل، وما يتأثر شي)
1. github.com ← Settings ← Billing and plans ← Upgrade to Pro.
2. المستودع ← Settings ← General ← آخر الصفحة ← Change visibility ← Make private.
3. Settings ← Pages: تأكد إن الدومين `najdacdemy.com` باقي، وإن Enforce HTTPS مفعّل.

**مهم:** لا تقفل المستودع قبل الاشتراك في Pro، لأن الموقع بيطيح على طول.

### ٢) نقل المستودع لمنظمة باسم محايد (مجاني، يخفي الحساب الشخصي)
- سوّ منظمة GitHub مجانية باسم مثل `najd-academy`، وانقل المستودع لها (Settings ← General ← Transfer ownership). يبقى عام، بس يطلع اسم المنظمة مو حسابك.
- الموقع والتذكيرات يكملون مجانًا.
- بعد النقل:
  - تأكد من الدومين في Settings ← Pages.
  - تأكد إن أسرار التذكيرات انتقلت في Settings ← Secrets.
  - أعطِ Claude صلاحية على المستودع بالاسم الجديد.
- **العيب:** الكود يبقى مكشوف لأي أحد يدور عليه.

### ٣) نقل الاستضافة لـ Cloudflare Pages (مجاني، وخاص كامل)
- Cloudflare يستضيف الموقع من مستودع خاص مجانًا.
- **يحتاج:**
  - نقل الـ DNS حق الدومين لـ Cloudflare (تغيير الـ Nameservers عند شركة الدومين).
  - تخفيف جدول التذكيرات عشان يدخل تحت ٢٠٠٠ دقيقة، مثل إلغاء التشغيل كل ساعة للتجارب.
- **العيب:** أطول طريقة في الإعداد.

## أي وحدة تختار
- **تبي بس اسمك ما يطلع:** الطريقة ٢.
- **تبي الكود نفسه ما أحد يشوفه:** الطريقة ١. أو الطريقة ٣ لو تبيها مجانية وما عندك مانع من الإعداد الأطول.
